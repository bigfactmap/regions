🔑 Ligar ao GitHub (só 1 vez)

Para publicar, o back office precisa de uma chave do GitHub. Fica guardada só neste browser.

  1. Passo 1 — Abre GitHub → novo token (conta bigfactmap).
  2. Passo 2 — Nome: backoffice. Validade: 1 ano.
  3. Passo 3 — Repository access: Only select repositories → regions.
  4. Passo 4 — Permissions → Repository → Contents: Read and write.
  5. Passo 5 — Generate token → copia e cola aqui.
